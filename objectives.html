Game Design Objectives

Core Goals & Career Milestones

Six key objectives guiding my growth as a game designer, asset creator, and developer.

Full Game Production

Collaborate and work with a proper game development company to create a full game.

Objective 2 • Marketplace Tools

Asset Store Development

Create fully functioning assets for the Unity store and other markets for game creation and design.

Objective 3 • Gameplay Systems

Innovative Game Mechanics

Create innovative game mechanics to make engaging and immersive mechanics.

Objective 4 • Spatial Architecture

Scoped Level Design

Make fully functioning Game levels for games that are perfect for the scope of the game itself.

Objective 5 • Career Readiness

Industry Skill Acquisition

Acquire the skills and fulfill requirements to be hireable in the game design field.

Objective 6 • Independent Release

Solo Indie Development

Make my own fully functioning and immersive game as an Indie developer.
